# Config (workspace root)

`config/specialists.json` and `config/stacks.json` are required when the workspace is the repo root (e.g. MCP development).

**Canonical source:** `packages/pn-core-mcp/content/config/`. Plugin `plugins/pnCore/config/` is synced from there. When using the plugin, open `plugins/pnCore` as workspace; config lives there.
