# Source Validation Tiers

pnCore skills and recommendations that assert "best practice" or "industry standard" must cite credible sources. This document defines source tiers and the validation rule.

---

## Tier 1 — Proven

| Source type | Examples |
|-------------|----------|
| UX research | Nielsen Norman Group (nngroup.com) |
| Standards | W3C, ISO |
| Peer-reviewed | ACM/IEEE/CHI papers |

**Use:** Required for claims about "best practice" or "industry standard." Skills asserting evidence-based practice must cite at least one Tier 1 source for their core claims.

---

## Tier 2 — Established

| Source type | Examples |
|-------------|----------|
| Methodology | Interaction Design Foundation |
| Design systems | gov.uk, Polaris, Material Design |
| Standards docs | OWASP (for security) |

**Use:** Acceptable for methodology guidance. Prefer citing alongside Tier 1 when possible.

---

## Tier 3 — Unverified

| Source type | Examples |
|-------------|----------|
| Agency blogs | Individual consultancies |
| Tool vendors | Product marketing |
| Listicles | "Top 10 X" articles |
| Unlinked statistics | "X% of teams" without source |

**Use:** Do not use for "best practice" claims. Treat as exploratory only.

---

## Validation Process

Before adding a skill that claims best-practice or industry-standard behavior:

1. **Identify core claims** — What assertions does the skill make?
2. **Find Tier 1 support** — Search NNG, W3C, or academic databases for each claim.
3. **Document citations** — Add a "Sources" or "Evidence" section to the skill with URLs and short excerpts.
4. **If no Tier 1 support** — Rephrase as "common practice" or "often recommended"; or defer until evidence is found.

---

## What to Avoid

- Citing Tier 3 sources as the sole basis for recommendations
- Claiming "industry standard" without a Tier 1 reference
- Using unverifiable statistics (e.g. "93% of teams") for best-practice claims
