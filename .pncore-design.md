# Design Context

> House design context for **pnCore**'s own surfaces: README SVGs, `docs/dashboard/`, any page this repo ships. Skills and commands read this file first. Downstream projects keep their own `.pncore-design.md`; nothing here carries over to them.
> Last updated: 2026-11-22

## Audience

Technical builders, design-conscious teams and practitioners who run Cursor, Claude Code, Codex or Pi with MCP for serious product work.

## Job to Be Done

Make AI-assisted development feel intentional. Documentation, plugin UX and references read as authored craft, not template output.

## Brand Personality

Precise, terse, a little arcade. One red signal on near-black: the engine is on, and it says so.

## Visual Ambition

Distinctive on public surfaces (README, docs, dashboard). Polished minimum for internal artifacts unless the task says otherwise.

## Reference Feel

The README SVGs and `docs/dashboard/` are the reference. Pixel display type over a mono body, flat near-black grounds, hairline borders, one accent. No gradient blobs, no floating cards on white, no robot or sparkle icons, no glass.

## Tokens

Color. Ratios are WCAG 2.x, computed against the ground they sit on, not estimated.

| Token | Value | Use | On `#0e0e0e` | On `#0a0a0a` |
|---|---|---|---|---|
| `ground` | `#0e0e0e` | page background | n/a | n/a |
| `ground-deep` | `#0a0a0a` | alternate ground, inset panels | n/a | n/a |
| `border` | `#2a2a2a` | hairlines, dividers, cell edges | 1.34 | 1.38 |
| `text` | `#e8e8e8` | body and display text | 15.76 | 16.16 |
| `text-secondary` | `#8c8884` | labels, captions, secondary text | 5.49 | 5.63 |
| `text-muted` | `#686868` | large text (24px+, or 18.66px+ bold), non-text marks | 3.46 | 3.55 |
| `accent` | `#dc2626` | fills, borders, focus rings, large text | 4.00 | 4.10 |
| `accent-text` | `#f87171` | accent at small text sizes | 6.98 | 7.16 |
| `accent-muted` | `#2a0f0f` | accent tint behind `accent-text` (6.47) or as a bar track | n/a | n/a |

Rules that follow from the numbers:

- `text-muted` and `accent` fail AA for small text on both grounds. Use them only for large text, borders and non-text marks (3:1 floor), or switch to `text-secondary` and `accent-text`.
- Re-compute any new pair before shipping it. Add the row here when it becomes a token.

Type.

| Token | Family | Use |
|---|---|---|
| `display` | Press Start 2P | headings, logo word, large numerals; sizes in multiples of 8px from 16px up, no negative tracking, weight 400 |
| `body` | DM Mono (400, 500) | body, labels, tables, code |

Small numerals and badges set in `body`, not `display`: the pixel face is drawn on an 8px grid, renders crisp only at multiples of it and is hard to read at body sizes.

## House philosophy

- Typography carries structure; color and motion support it.
- One orchestrated entrance on key pages; no scattershot micro-motion. Respect `prefers-reduced-motion`.
- Tokens as CSS variables for color, spacing and type; no magic numbers in components.
- Accessible by default: computed contrast, visible focus, touch targets.
- Before calling UI done on a public surface, render it in a real browser and look at the screenshot (`pn-evidence-qa` when available).
