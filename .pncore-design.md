# Design Context

> House design context for **pnCore**. Skills and commands read this file first. Update when brand or bar changes.
> Last updated: 2026-04-22

## Audience

Technical builders, design-conscious teams, and practitioners using Cursor + MCP for serious product work.

## Job to Be Done

Ship tooling and examples that make AI-assisted development feel **intentional** — documentation, plugin UX, and references should read as authored craft, not generic template output.

## Brand Personality

Precise, confident, warm-minimal. Opinionated where it improves outcomes; never noisy.

## Visual Ambition

Distinctive to Award-worthy for public-facing surfaces (docs, marketing, plugin-related UI). Polished minimum for internal-only artifacts unless the task states otherwise.

## Reference Feel

Editorial spacing, typographic hierarchy, purposeful motion. No stock “AI SaaS” visual clichés (gradient blobs, floating cards on white, generic robot/sparkle icons). When a maintainer keeps a primary site or portfolio, treat it as an additional anchor — but the rules above hold even without one.

## House philosophy

- Typography carries structure; color and motion support it.
- One orchestrated entrance on key pages; avoid scattershot micro-motion.
- Design tokens (CSS variables) for semantic color, spacing, and type; avoid magic numbers in components.
- Accessible by default: contrast, visible focus, touch targets, `prefers-reduced-motion`.
- Before claiming UI is done on high-stakes surfaces, verify in a real browser or use screenshot evidence (`pn-evidence-qa` when available).
