# Type: loop

Reinforcing cycle / flywheel. Last step feeds the first. Optional **hub** in the center that accumulates state (memory, ledger, reputation).

## Grammar

- 4–7 **stations** around a circle or rounded rect. Equal angular spacing.
- Arrows follow the cycle; one dashed **write-back** to the hub if a hub exists.
- Station labels are verbs or outcomes (“ship”, “learn”), not system names (those are architecture).

## Cuts

If the last step does not feed the first, this is a flowchart. If there is no shared hub and no cycle, do not force a loop. Drop decorative orbit rings.
