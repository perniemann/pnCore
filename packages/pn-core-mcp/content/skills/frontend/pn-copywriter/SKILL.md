# Copywriter skill

## When to use

- Writing or rewriting service/portfolio copy, landing pages, hero sections, CTAs
- Creating brand-agnostic copy that fits an existing brand's voice
- Structuring proof, offer taxonomy, and conversion paths
- Diagnosing brand positioning before writing

## Workflow

1. **Input:** Read user-provided copy, brand doc, existing site, or reference material. If none: ask "Paste copy to analyze, share a URL, or describe the brand and offer."
2. **Diagnose:** Run A (ICP, offer maturity, positioning, price-tier, conversion hierarchy). Output diagnosis table.
3. **Fingerprint:** Run B (voice, tone sliders, lexicon, rhythm). Output style fingerprint.
4. **Structure:** Run D + E (proof map, CTA ladder, narrative path).
5. **Declare mode:** State operating mode (strict mimic / adapted mimic / evolved style) before rewriting.
6. **Rewrite:** Produce rewrite pack. Run QA score. Claim-safe only.

## Input

- **Required for diagnosis:** Existing copy, brand doc, or site URL. Agent infers ICP, positioning, tone from this.
- **If missing:** Ask user to paste copy, share URL, or describe brand + offer. Do not diagnose from thin air.

## A) Diagnose before writing

1. **ICP:** Infer primary ICP from services, proof, project mix, CTA style. Output: Primary ICP / Secondary ICP / Evidence / Confidence.
2. **Offer maturity:** Label execution-led / strategy-led / hybrid. Determines concept vs deliverable language balance.
3. **Positioning:** Label specialist / method-specialist / generalist. Method-specialist suits broad portfolios.
4. **Price-tier:** Label premium / upper-mid / accessible from proof quality, tone, CTA friction. Sets tone sharpness and CTA commitment.
5. **Conversion hierarchy:** Primary CTA / Secondary CTA / Trust path. Example: contact first | social proof second | portfolio third.

## B) Style fingerprint

- **Voice:** Personal expert, accountable. First-person or direct expert framing. Not anonymous agency tone.
- **Lead with outcomes:** Frame what the writing changes for the buyer before listing deliverables.
- **Tone:** Warm + clear + controlled. Approachable confidence; not chatty, not stiff. Friendly wording + precise structure.
- **Anchored claims:** Pair expressive language with concrete channels, outputs, use cases.
- **Verbal consistency:** One throughline across channels. Same voice for web, campaigns, UX, editorial.
- **Tone sliders:** Score 1–3 (low/mid/high) per axis. Use to control rewrites. Axes: formal/conversational | warm/neutral | playful/serious | minimal/elaborate | bold/cautious | premium/accessible.
- **Lexicon:** Allowed = fit clarity, warmth, sophistication. Discouraged = jargon, over-salesy, vague-superlative, overly corporate.

## C) Rhythm and formatting

- **Sentence rhythm:** Short-to-medium lines; occasional medium-length clarifiers. No long dense paragraphs unless page type requires depth.
- **Paragraph pattern:** Short opener / clarifying line / practical line.
- **Contrast:** Use opposites (creative/practical | broad/specific | simple/sophisticated) to show range without length.
- **Modular sections:** Many compact blocks, not few large blocks. Improves scannability.
- **Headings:** Short, functional scan anchors. Orient the reader; don't just perform tone.
- **Format rules:** Set limits for heading length, paragraph length, list density, tag style, whitespace. Preserve patterns across rewrites.

## D) Offer and proof structure

- **Taxonomy:** Group capabilities into labeled categories (not flat list).
- **Service tags:** Attach tags to proof units. Every project shows what work it demonstrates.
- **Channel range:** Indicate where work lives (web / campaign / product / editorial / brand system).
- **Proof module format:** client/brand | category | service tags | short summary | assets/links. More scalable than full case studies.
- **Named brands when metrics unavailable:** Use recognizable collaborators/contexts. Do not fake performance claims.
- **Repeat trust:** Highlight retainer, repeat projects, ongoing collaboration where true.
- **Cross-industry consistency:** Same capability repeats across sectors. Avoid "generalist without edge."
- **About section:** Signal collaboration style, strategic involvement. Move perception from "copy vendor" to "thinking partner."

## E) Conversion and CTA

- **Narrative path:** intro/positioning → capabilities → proof → credibility → personal fit → CTA.
- **CTA ladder by friction:** Low = message/email/contact. Mid = brief/fit check. High = consultation/kickoff. Don't use same CTA strength everywhere.
- **Repeat low-friction CTAs:** Hero, after proof, footer. Add trust path (social, portfolio, credentials) for users not ready.

For page layout, hero anatomy, and CTA placement, reference pn-landing-page.

## Required outputs

Produce these artifacts when applying:

- ICP classification | primary + secondary + confidence
- Offer maturity | execution/strategy/hybrid + positioning + price-tier
- Style fingerprint | voice + tone sliders + lexicon + rhythm + format rules
- Proof map | proof modules tagged by service + strength notes
- CTA ladder map | CTA level by section/page
- Conversion narrative map | intro → capabilities → proof → fit → CTA
- Rewrite pack | in extracted style, claim-safe only
- Rewrite QA score | voice match / clarity / proof alignment / CTA fit / originality

**Claim-safe:** Only state outcomes, metrics, or clients evidenced in the source. No invented results, no overclaim.

**Example (ICP classification):** Primary: B2B marketing leads at series A–B | Secondary: in-house teams needing voice consistency | Evidence: case mix, CTA "Book a call" | Confidence: high

## Operating modes (declare before rewriting)

State which mode you are using before producing the rewrite pack.

- **Strict mimic:** Preserve style DNA closely (tone, rhythm, formatting, CTA style).
- **Adapted mimic:** Preserve voice principles; adapt vocabulary and proof framing to new market.
- **Evolved style:** Preserve core voice; improve conversion structure, proof depth, CTA system.

## Hard safety rules

- Do not invent metrics, outcomes, clients, or credentials.
- Do not overclaim strategic work if only execution is evidenced.
- Do not copy source phrasing or sentence shapes.
- Do not let tone become generic-corporate during "optimization."
- Do not improve conversion at the cost of voice consistency.
