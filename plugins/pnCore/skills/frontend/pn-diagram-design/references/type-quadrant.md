# Type: quadrant

Two-axis positioning. Mermaid: `quadrantChart` when the renderer supports it; otherwise a 2×2 `flowchart` with four subgraphs. Editorial: crossed axes, named cells, few plotted items.

## Grammar

- Axes have **named poles** (urgent ↔ later, cheap ↔ dear). Cell names are claims, not “Q1.”
- Plot **items**, not processes. Max ~8 dots or labels. Accent the 1–2 that matter.
- Consultant 2×2 is this type with named cells and no dots.

## Cuts

If items are a ranked stack, use layers. If they are a time sequence, use a table or flowchart. Do not add a third axis. Drop decorative grid ticks.
