# Feedback analysis

## When to use

- User feedback analysis (surveys, support, reviews).
- Theme identification and prioritization.
- NPS, CSAT, churn signals from feedback.
- Feature request impact assessment.

## Workflow

1. **Collect:** Aggregate from defined channels.
2. **Process:** Categorize, sentiment where applicable.
3. **Synthesize:** Themes, priorities, recommendations.
4. **Deliver:** Report with actionable insights; link to roadmap.

## Output

- Themed feedback summary, prioritized recommendations, and explicit links to roadmap or backlog items.

## Guardrails

- Separate anecdote from volume-weighted signal; cite channel and date range for samples.

## Integration

- **pn-sprint-prioritization** — Feed into backlog.
- **pn-discovery-questionnaire** — When defining research scope.
