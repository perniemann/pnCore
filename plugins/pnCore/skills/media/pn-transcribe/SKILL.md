# Transcription and captions (STT)

## When to use

- Generating a timestamped SRT or VTT caption track from narration audio produced by `pn-tts`.
- Transcribing screen recording audio, interview recordings, or voiceover for accessibility compliance.
- Producing word-level timestamps for caption-synced animation (bouncy captions, karaoke-style reveals).
- Validating that AI-generated TTS matches the intended script (hallucination check).

## Tool selection

| Tool | Model | Best fit | Notes |
|------|-------|----------|-------|
| **Whisper (OpenAI API)** | `whisper-1` | Quick, accurate, many languages, word timestamps | `response_format: verbose_json` for timestamps |
| **Whisper (local / faster-whisper)** | large-v3, medium | Offline, batching, custom alignment | faster-whisper is 4× faster than original; CTranslate2 backend |
| **AssemblyAI** | Universal-2 | Speaker diarization, auto-chapters, redaction | Best for multi-speaker; paid per minute |
| **ElevenLabs timestamps API** | — | When audio was generated by ElevenLabs TTS | Returns character-level alignment; no separate transcription step |
| **Gentle (forced alignment)** | Kaldi | When you have the transcript and just need timestamps | Requires known-correct transcript; aligns speech to text exactly |

**Default:** Whisper via OpenAI API (simple, no infra) or faster-whisper local (batch, cost-sensitive, offline).

## Workflow

### 1. Pre-process audio

Ensure clean audio before transcription — noise, music, and reverb increase error rate.

```bash
# Strip music bed, keep voice (if isolated tracks are available)
# Normalize loudness
ffmpeg -i narration.wav -af loudnorm=I=-14:TP=-1:LRA=11 narration-clean.wav
```

### 2. Transcribe with word-level timestamps

**OpenAI API:**
```python
from openai import OpenAI
client = OpenAI()

with open('narration-clean.wav', 'rb') as f:
    result = client.audio.transcriptions.create(
        model='whisper-1',
        file=f,
        response_format='verbose_json',
        timestamp_granularities=['word', 'segment'],
    )

# result.words: [{'word': 'Hello', 'start': 0.0, 'end': 0.24}, ...]
# result.segments: segment-level blocks for SRT generation
```

**faster-whisper (local):**
```python
from faster_whisper import WhisperModel

model = WhisperModel('large-v3', device='cuda', compute_type='float16')
segments, info = model.transcribe('narration-clean.wav', word_timestamps=True)

for segment in segments:
    for word in segment.words:
        print(f'{word.start:.2f}s  {word.end:.2f}s  {word.word}')
```

### 3. Generate SRT / VTT

SRT format:
```srt
1
00:00:00,000 --> 00:00:03,200
Welcome to the plugin demo.

2
00:00:03,400 --> 00:00:07,100
Today we're covering three key features.
```

VTT format (preferred for web/HTML video):
```vtt
WEBVTT

00:00:00.000 --> 00:00:03.200
Welcome to the plugin demo.

00:00:03.400 --> 00:00:07.100
Today we're covering three key features.
```

**Grouping words into caption blocks:**
- Max 2 lines per block; max 42 characters per line.
- Max 17 CPS (characters per second) — standard accessibility target.
- Min 1.0s per block; pad short blocks to avoid flash captions.
- Gap between blocks ≥ 0.2s to allow clear reading transition.

Simple Python grouping:
```python
def words_to_srt(words, max_chars=42, max_cps=17):
    blocks, buf, buf_start = [], [], None
    for w in words:
        buf.append(w)
        if buf_start is None:
            buf_start = w['start']
        line = ' '.join(x['word'] for x in buf)
        duration = w['end'] - buf_start
        cps = len(line) / max(duration, 0.01)
        if len(line) > max_chars or cps > max_cps:
            blocks.append((buf_start, buf[-2]['end'], ' '.join(x['word'] for x in buf[:-1])))
            buf = [w]; buf_start = w['start']
    if buf:
        blocks.append((buf_start, buf[-1]['end'], ' '.join(x['word'] for x in buf)))
    return blocks
```

### 4. Hallucination check

Compare the generated transcript against the original TTS input script:
- **Character-level diff:** Flag any inserted, deleted, or substituted words.
- **Common hallucinations:** Whisper adds filler words ("um", "uh"), mishears acronyms, and occasionally invents a sentence at the end of a short clip. Remove inserted fillers; correct proper nouns manually.
- **Confidence threshold:** faster-whisper provides per-word `probability`; flag words below 0.6 for manual review.

```python
import difflib
script_words = original_script.lower().split()
transcript_words = transcript.lower().split()
diff = list(difflib.unified_diff(script_words, transcript_words, lineterm=''))
hallucinations = [l for l in diff if l.startswith('+') and not l.startswith('+++')]
```

### 5. Embed captions in video

**ffmpeg (burn-in for social):**
```bash
ffmpeg -i output.mp4 -vf "subtitles=captions.srt:fontstyle=bold:fontsize=22" output-captioned.mp4
```

**HTML video element (web / composition):**
```html
<video src="output.mp4">
  <track kind="subtitles" src="captions.vtt" srclang="en" label="English" default>
</video>
```

**Composition `data-*` caption clip (Hyperframes pattern):**
```html
<track
  id="captions"
  data-start="0"
  data-duration="30"
  data-track-index="5"
  src="captions.vtt"
  kind="subtitles"
  default>
```

## Caption formatting standards

| Spec | Target |
|------|--------|
| Max CPS | 17 (standard) / 20 (fast-paced social) |
| Max chars per line | 42 |
| Max lines per block | 2 |
| Min block duration | 1.0s |
| Gap between blocks | ≥ 0.2s |
| Language tag | `srclang="en"` / ISO 639-1 |
| Kind | `subtitles` (spoken dialogue) or `captions` (includes non-speech) |

## Guardrails

- Always derive captions from the **rendered audio**, not from the input script — TTS may deviate.
- Do not use auto-generated captions as the final accessibility track without a hallucination review.
- For multi-speaker content, use a diarization tool (AssemblyAI or pyannote) before caption grouping — mixing speakers in one block is confusing.
- Timestamps must reference the final composed audio position, not the raw narration file. Offset by `data-start` of the audio clip in the composition.
